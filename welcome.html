SymbolGen

Symboles Unicode & Formules LaTeX par IA

1

Obtenez votre clé API gratuite

SymbolGen utilise Groq pour comprendre vos descriptions en français ou en anglais. La clé est gratuite et s'obtient en 30 secondes.

Créer ma clé sur console.groq.com →
2

Entrez-la dans les Options

Cliquez sur le bouton ci-dessous pour ouvrir la page de configuration et coller votre clé gsk_....

3

Cherchez n'importe quel symbole

Tapez une description en français ou en anglais — "environ égal", "flèche droite", "intégrale" — et cliquez sur le résultat pour l'insérer ou le copier.

environ égal → ≈ pas égal → ≠ infini → ∞ pour tout → ∀ delta majuscule → Δ copyright → ©
4

Générez des formules LaTeX

Utilisez l'onglet Formules pour décrire une équation en langage naturel et obtenir le code LaTeX avec un rendu visuel.

y égal 2x² plus 5 intégrale de 0 à infini de e^-x²
Astuce : Appuyez sur Alt+S pour ouvrir SymbolGen depuis n'importe quelle page.
